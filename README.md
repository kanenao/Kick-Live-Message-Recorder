## β版と製品版の保守方針

β版では新機能と不具合修正を継続します。**製品版は致命的な不具合がない限り、月1回程度のまとめた修正リリース**とし、β版の未検証機能は自動で製品版へ反映しません。録画不能・データ破損・重大なセキュリティ障害などは、必要に応じて月次を待たず緊急修正します。詳しくは[版の運用方針](docs/RELEASE_CHANNELS.md)をご確認ください。

## 1.0.1-beta.95（公開済みβ版）―β版の基本番号を製品版1.0.1と統一

- **製品版の公開バージョン `1.0.1` に基本番号を合わせます。** β版を `0.9.0-beta.94` → `1.0.1-beta.95` へ更新します。`beta.95` は従来の `beta.94` に続く通し番号で、基本番号の変更時もリセットしません。
- 今後は公開済みの最新製品版をGitHub Releasesで確認し、β版の基本番号がそれより古い場合は引き上げます。β版側で先行開発している場合、製品版が更新されてもβ版の基本番号を下げません。
- **開発規模による番号の付け方：** 日常の調整は基本番号を維持して `beta.N` だけ進めます。まとまった不具合修正はパッチ番号、比較的大きな機能追加はマイナー番号、互換性の大きな変更はメジャー番号を上げます。
- 版番号の計画を再現できるよう `node scripts/plan-next-beta-version.mjs 1.0.1 sync` を追加します。`sync`／`maintenance`／`patch`／`feature`／`breaking` を選べます。これはバージョン候補の算定用で、リリースの公開は別途テスト成功後だけです。
- **製品版の更新周期は変えません。** 製品版は原則月1回、緊急の致命的な不具合のみ随時修正します。β版だけに配信AI新聞を残し、製品版をβ版へ勝手に切り替えたり、製品版インストーラーを自動取得したりしません。

## 0.9.0-beta.93（公開済みβ版）―製品版の誤ダウンロードを禁止

- β版の自動更新対象はGitHub Releasesに公開済みの**β版のみ**。最新版β版のインストーラーと `beta.yml` を検証し、ダウンロードする版が一致した場合だけ自動取得します。製品版の公開がβ版より新しくても、β版から勝手に製品版は取得しません。

- Windowsにβ版を起動した履歴を保持し、**以前のβ版ユーザーのみ**製品版1.0.1以降の「β版に戻る」を利用できるようにします。旧β版の履歴がない場合はβ93を一度起動すると利用履歴が登録されます。
- 履歴は同じWindowsユーザーのローカル領域にのみ保存し、パスワードや配信情報は保存しません。β版と製品版は別アプリとして存続し、録画・コメント・記事を削除しません。

## 主な機能

### 配信監視・録画
- Kickチャンネルの登録と、通常チャンネル／録画専用チャンネルの管理
- バックグラウンドでの配信状態監視（設定可能・最短10秒間隔）

- 配信開始通知と自動録画、一覧からの手動録画
- yt-dlp・FFmpegによる映像／音声の保存と自動結合
- 録画エラー時の自動再接続
- 録画中のKick公式プレーヤープレビュー
- Kick VODのURL指定ダウンロード

### コメント取得・保存
- Kickコメントのリアルタイム受信とアプリ内表示
- チャンネル別・配信日時別のJSONL保存（旧日付単位ファイルも読み込み可能）
- 投稿者名・本文・時刻・バッジ・エモート等の記録
- LIVEコメントの自動取得とVODコメント履歴の取得（JSONL・TXT・ASS字幕を出力）

### ニコ生風コメント付き動画
- 録画動画とコメントログを合成してMP4を生成
- 白文字・太い黒フチ・影によるニコ生風表示
- 右から左へのスクロール、上部固定、下部固定、コメントごとの位置指定
- 長文・短文の移動速度調整と、同じ行でのコメント衝突回避

## α版のリリース運用

今後はα版として開発・テストを進めます。α版の公開は `v*-alpha*` タグだけを使用し、β版タグ・通常の製品版タグではα版公開ジョブを実行しません。開発ブランチへの通常のpushは検証用ビルドであり、それだけで一般公開されません。α60のみ、明示的な公開依頼に対応する一回限りの公開ジョブで、テストとWindows成果物の検査後にタグとPre-releaseを作成します。以前の未公開開発番号β51・β52は、番号を保ったままα51・α52へ移行しました。過去に公開したβ50は公開履歴として残します。

### バージョン番号の決め方

バージョンは `MAJOR.MINOR.PATCH-alpha.N` 形式で管理します。現在の開発版は `0.2.7-alpha.62` です。今回のPATCH更新は、α版の自動更新チャンネル修正です。

- **PATCH**：既存機能の不具合修正、安定性・性能改善、小規模な調整（次回例：`0.2.7-alpha.62`）。
- **MINOR**：互換性を保った主要機能の追加・拡張、開発上の大きな節目（次回例：`0.3.0-alpha.62`）。
- **MAJOR**：安定版公開後の大きな互換性変更。初回の `1.0.0` は製品版の安定性基準を満たした段階で判断し、番号だけを理由に早めない。

`alpha.N` は上記3つの数字とは独立したα版の開発連番です。開発を進めるたびに `52 → 53 → 54 → 55 → 56 → 57` と増やし、PATCH／MINOR／MAJORを更新しても連番をリセットしません。次回は内容に応じて `0.2.7-alpha.62` または `0.3.0-alpha.62` のように判断します。
