# Kick Live Message Recorder

Kick のライブ配信を録画し、チャットを保存する Windows デスクトップアプリです。

<aside>
<strong>開発版：0.1.0-beta.8</strong><br />
配信状態の自動監視・Windows通知・日本語メニュー・自動更新に加え、yt-dlpによる手動/自動録画の初期実装に対応しています。チャット取得と録画ライブラリは引き続き開発中です。
</aside>

## 自動アップデートについて

- Windows版は起動時と6時間ごとにGitHub Releasesを確認します。
- 新版があれば自動でダウンロードし、アプリ終了時に適用します。設定画面から手動確認・即時再起動もできます。
- β版の更新公開は `v0.1.0-beta.5` のように、`package.json` のバージョンと一致するタグを作成してpushします。GitHub ActionsがWindowsインストーラーと更新情報ファイルをReleaseへ公開します。
- β2以前は自動更新機能を含まないため、β3は手動インストールが必要です。β3以降は自動更新に対応します。
- 現在のWindowsビルドにはコード署名証明書がありません。更新ファイルはHTTPSとSHA-512で検証しますが、発行元のAuthenticode署名検証は無効化しています。将来の一般配布前にコード署名証明書を導入することを推奨します。

## 動作確認・開発

Node.js 22 以上を用意し、次を実行します。

```bash
npm install
npm run dev
```

Windows向けインストーラーをローカルで作成する場合：

```bash
npm run dist:win
```

GitHub Actionsでは、mainブランチのビルドをActions Artifactsに14日間保存します。バージョンに一致する `v*` タグをpushすると、Windowsインストーラーと自動更新用ファイルをGitHub Releasesへβ版として公開します。

## メニューの日本語化

Windowsアプリ上部の「ファイル」「編集」「表示」「ウィンドウ」「ヘルプ」を日本語で表示します。テキスト入力欄やリンク上の右クリックメニューも日本語化し、GitHubリポジトリ、不具合報告、バージョン情報へアクセスできます。

## 参考アプリから取り入れた設計

- KickChecker：配信の定期監視、監視間隔設定、配信開始通知、通信エラー後の再確認
- KickLiveRecorder：録画エンジン（yt-dlp/FFmpeg）、再接続、保存容量監視、ファイル名・フォルダー名テンプレート、コメント出力形式
- KickMessageRecorder：チャット時刻同期、エモート処理、XML/SRT/ASS出力、コメント色分け

チャットのリアルタイム取得は、参考アプリが利用しているPusher接続をそのままコピーせず、Kick公式イベント/APIの認証・公開Webhook要件を満たす方法を優先します。Kick公式Webhookの受信先はインターネットから到達可能である必要があります。

## Kick API接続設定

Kick Developerでアプリを作成し、発行されたClient IDとClient Secretをアプリの設定画面に登録してください。Client SecretはWindowsのElectron safeStorageで暗号化し、レンダラーには渡しません。配信状態の確認にはKick公式の `GET /public/v1/channels` を利用します。最大50チャンネルずつ問い合わせ、ストリームキーや配信URLなどの機密フィールドは使用しません。

## データ保存

- チャンネル一覧と設定はElectronのユーザーデータ領域にJSON形式で保存します。
- 録画ファイルの保存先は設定画面から選択できます（保存先は録画エンジンで利用します）。
- ブラウザープレビューでは、設定をブラウザーのlocalStorageに保存します。

## 録画エンジンのセットアップ（β7）

1. yt-dlpの公式GitHub ReleasesからWindows用の `yt-dlp.exe` を取得します。
2. FFmpegを利用できるようにします。PATHに登録するか、設定画面で `ffmpeg.exe` を指定してください。
3. Kick Live Message Recorderの「設定」→「録画エンジン」で `yt-dlp.exe` と必要に応じて `ffmpeg.exe` を選択します。
4. 保存先を設定し、ダッシュボードで配信中のチャンネルに「録画開始」を押します。

yt-dlpは外部実行ファイルとして利用し、本アプリのインストーラーには同梱しません。Kick対応はyt-dlp側の更新やKickの配信仕様変更に影響されます。録画開始時点より前の映像は取得しません。配信終了時は録画処理も終了します。ネットワーク異常終了時のみ、最大5回の再接続を試みます。

- yt-dlp: https://github.com/yt-dlp/yt-dlp/releases
- FFmpeg: https://ffmpeg.org/download.html

## コメント付き動画の作成（β8）

1. 「コメント付き動画」画面で録画済み動画を選択します。
2. コメントログまたはASS字幕を選択し、読み込み形式とコメント件数を確認します。
3. 出力先MP4を選び、フォントサイズ・流れる速さなどを調整して生成します。
4. コメントの時刻補正（秒）と表示スタイルを調整し、FFmpegがコメントを映像に焼き込んだMP4を書き出します。

対応コメント形式：
- **ASS**：既存のASSイベント・配置・色・スタイルを使ってそのまま合成（NicoConvAss出力を想定）
- **JSON**：コメント配列。時刻は `time` / `offset` / `seconds`（秒）、ニコ生形式の `vpos`（1/100秒）に対応。本文は `text` / `comment` / `message` 等
- **CSV**：ヘッダー付き（time/text/user/color/position等）または、時刻・ユーザー名・本文の順の列
- **XML**：`chat` / `comment` / `message` 要素。時刻属性と本文要素を読み込み
- **TXT**：時刻・ユーザー名・本文をタブ区切り、または「時刻 本文」の行形式
- **SRT**：字幕の開始時刻と本文を読み込み、スクロールコメントとして変換

FFmpegにはASSフィルターが必要です。利用するFFmpegビルドによってはASS/libassが含まれない場合があります。FFmpegのASSフィルターはASS字幕を映像に描画するためのフィルターです（[公式ドキュメント](https://ffmpeg.org/ffmpeg-filters.html#ass)）。

**重要:** Kickのチャット自動取得機能はまだ開発中です。この画面は、現時点では外部ツールなどで保存したコメントファイルを読み込んで動画化する機能です。元動画の録画開始時刻とコメント時刻が合っている必要があります。日付付きの絶対時刻だけのログは、動画内の相対秒へ変換してから読み込んでください。
