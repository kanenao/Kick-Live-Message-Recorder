# Kick Live Message Recorder

Kick配信の録画・コメント保存を行うWindowsデスクトップアプリです。

**開発版：0.1.0-beta.30**

## 主な機能

- Kickチャンネルの登録・削除
- 配信中／オフライン状態の確認と24時間バックグラウンド自動監視（通知領域常駐・Windowsログイン時の自動起動）
- LIVE中の配信者カード（通常チャンネル・録画専用チャンネルの表示名・プロフィール画像・配信タイトル・カテゴリ・開始時刻・経過時間・視聴者数）
- 配信開始時のWindows通知と自動録画・コメント自動接続（通常チャンネルと録画専用チャンネルを設定で対象化）
- チャンネル管理とは独立した「録画専用」一覧（手動録画）
- 通常チャンネル・録画専用チャンネルそれぞれのコメント自動取得ON／OFF
- 録画専用チャンネル一覧からのワンクリック映像録画＋コメント取得
- アプリ起動時・チャンネル追加時のKickチャット自動接続
- Kickコメントのリアルタイム受信・JSONL保存・画面表示
- yt-dlp・FFmpegをアプリに同梱し、m3u8（HLS）配信の映像・音声を自動結合して保存
- 録画ファイル一覧・再生・保存先表示・個別削除（削除前に確認し、録画中のファイルは削除不可）
- 保存済みLIVE／VODコメントJSONLをASS字幕に変換して動画へ焼き込む「コメント付き動画」生成（LIVEは同じチャンネルの複数日ログをまとめて指定可能）
- 録画エラー時の自動再接続（回数・待ち時間を設定可能）
- 録画中チャンネルのライブ映像プレビュー（Kick公式埋め込みプレーヤー、設定でON／OFF可能）
- Kick過去配信（VOD）のURL指定ダウンロード
- Kick過去配信のコメント履歴ダウンロード（JSONL・TXT、配信経過時刻・ユーザー名・本文を保持）
- 登録配信者ごとの新聞記事風「配信記事」生成・保存（録画とコメントログの集計）
- 専用の「バージョン更新」画面（現在のバージョン・更新確認・ダウンロード進捗・再起動更新・リリースノート・過去の更新履歴）
- 起動時・定期的なアップデート確認

## バージョン更新

左メニューの「アプリ」→「バージョン更新」から、現在のバージョン、更新確認の状態、ダウンロード進捗、GitHub Releasesのリリースノート、過去の更新履歴を確認できます。「更新を確認」で手動確認し、新しい版が見つかるとバックグラウンドで自動ダウンロードします。ダウンロード完了後は「再起動して更新」から更新を適用できます。自動確認は起動時と約6時間ごとに行います。自動更新はWindowsインストーラー版が対象です。

## 配信記事

beta30で追加した記事生成機能です。

左メニューの「配信記事」から登録配信者と録画動画を選ぶと、同じ配信者の保存済みコメントログを集計して記事を生成します。記事は `Articles/配信者名/` にJSONで保存され、配信者別・放送日時順に一覧表示できます。記事には見出し、カテゴリ、コメント総数、投稿者数、頻出キーワード、コメント例、元動画へのリンクを含みます。記事本文はローカルのコメント頻出語と投稿サンプルを用いた簡易自動生成であり、映像内容をAIが理解した要約ではありません。来場者数などKick側から取得していない数値は推測して表示しません。

## 24時間バックグラウンド監視

beta29以降は配信監視をElectronメインプロセスで実行します。アプリのウィンドウを閉じても通知領域へ常駐し、最短10秒間隔で登録チャンネルのLIVE状態を確認します。配信開始を検知すると、通常チャンネルは「自動録画」モードの設定に従って録画を開始します。録画専用チャンネルの自動録画設定は通常チャンネルとは独立しており、こちらだけを自動録画ONにすることもできます。チャット自動取得が有効なチャンネルはコメントもJSONLへ保存します。起動直後にすでにLIVE中のチャンネルも検出対象です。

Windowsログイン時の自動起動を有効にすると、サインイン後に通知領域でバックグラウンド起動します。監視中のスリープ抑止設定も用意しています。有効時はWindowsのスリープとディスプレイ消灯を抑止するため、画面は点灯したままになります。画面右上の×はアプリ終了ではなく通知領域へ隠す操作です。完全終了は通知領域アイコンを右クリックして「アプリを終了」を選択してください。

**監視の制約：** Windowsがシャットダウン中、ユーザー未ログインで自動起動が未実行、ネットワーク切断、Kick APIの障害・アクセス制限中は監視できません。PCの電源を切る・休止状態にする・ノートPCのふたを閉じる設定によっては監視が止まります。10秒監視はAPIの応答遅延やアクセス制限がない場合の目安であり、配信開始と同時の検知を保証するものではありません。コメント受信はKickの非公式リアルタイム接続に依存し、再接続中のコメントは取得できない場合があります。

## コメント付き動画の生成

左メニューの「コメント付き動画」から、録画ライブラリの動画と `Chat/チャンネル名/` に保存されたJSONLコメントファイルを選択します。日付をまたいだLIVE配信は、同じチャンネルの対象日ログを複数選択できます（最大31ファイル）。異なるチャンネルのログやLIVEとVODの混在はできません。LIVEコメントは録画ファイル名に含まれる録画開始時刻を優先して同期し、名前を変更した動画などは更新時刻と再生時間から開始時刻を推定します。LIVEログが日付ごとに分割されている場合は、同じチャンネルの複数ファイルを選択してまとめて使用できます。VODコメントは取得時に保存した配信開始からの経過秒数を使って同期します。同期ずれは秒単位で調整できます。

コメントはNicoConvAssを参考にASS字幕として右から左へ流し、文字サイズ・表示時間・最大行数・不透明度・投稿者名表示を調整できます。行が重なる場合は別の行へ割り当て、表示可能な行がないコメントは省略します。動画とコメントを合成したMP4は `CommentVideos/` に保存し、元動画・元コメントは変更しません。エンコード画質は高画質・標準・容量優先から選択できます。HandBrake本体を起動するのではなく、アプリに同梱したFFmpegで処理します。

## 録画中の映像プレビュー

録画中のチャンネルがある場合、ダッシュボードと「録画専用」画面の上部にKick公式プレーヤーを表示します。設定画面の「配信プレビュー」で表示をON／OFFできます。OFFにしても録画・コメント取得には影響しません。複数チャンネルを同時録画している場合は、プレビューするチャンネルを切り替えられます。プレビューはミュート状態で自動再生を試みます。ブラウザーの自動再生制限やKick側の配信状態・埋め込み制限により、再生ボタンの操作が必要な場合があります。プレビューは視聴用で、録画処理・コメント受信とは独立しています。

## 過去配信（VOD）のダウンロード

「録画専用」画面の「過去の配信（VOD）を録画」に、KickのVideosページからコピーした `https://kick.com/チャンネル/videos/動画ID` のURLを貼り付けてダウンロードします。yt-dlpとFFmpegを使用し、動画ファイルとして録画ライブラリの保存先へ保存します。対象は公開状態で取得可能なVODです。チャンネル名とURL内のチャンネル名が一致することを検証します。同じURL入力欄から「過去配信のコメントを取得」を実行すると、VODの開始時刻・配信時間に合わせてKickのコメント履歴をページ取得し、`Chat/チャンネル名/` にJSONLとTXTで保存します。ライブコメントの受信とは別処理です。

## 録画方法

### チャンネル管理

1. ダッシュボードでKickチャンネルを登録します。
2. 自動モードなら配信開始を検知して自動録画します。手動モードなら一覧から「録画開始」を押します。
3. 設定画面の「Kickチャットを自動取得」がONなら、アプリ起動時やチャンネル追加時にコメントへ自動接続します。

### 録画専用

1. 左メニューの「録画専用」を開きます。
2. 録画したいKickチャンネル名またはURLを登録します。
3. 配信中に「録画開始」を押します。
4. チャンネル行の「録画＋コメント取得」を押すと、映像録画とコメント受信を同時に開始します。コメント自動接続も有効になり、次回起動後も自動接続します。上の設定をOFFにすると、次回起動時の自動接続を止められます。録画停止後もコメント受信は設定に従って継続します。

録画とコメント付き動画の生成には yt-dlp・FFmpeg・ffprobe を使用します。Windows版インストーラーには3つを同梱するため、別途インストールやPATH設定は不要です。HLS（m3u8）配信の映像・音声もFFmpegで自動処理します。FFmpegのライセンス文書とビルド情報はアプリのresources/tools内に同梱しています。

通信切断などで録画プロセスが異常終了した場合は、設定画面の「録画の自動再接続」で指定した回数・待ち時間に従って再接続します。初期値は5回・10秒です。手動停止または配信の正常終了では再接続しません。再接続後の録画は元のファイルを上書きしないよう、`_retry02` などの連番付きファイルとして保存します。

録画専用一覧は、配信状態の自動監視・配信開始時の自動録画には含まれません。コメント自動取得は通常チャンネルとは別にON／OFFできます。

## コメント受信

通常のチャンネル管理と録画専用の両方で、コメント自動取得を個別に設定できます。受信したコメントは画面に表示し、チャット保存が有効なら `Chat/チャンネル名/YYYY-MM-DD.jsonl` に保存します。同時接続は合計50チャンネルまでです。

ngrok、Cloudflare Tunnel、独自ドメイン、Webhook URL登録、コメント受信用の追加トークンは不要です。

### コメント受信方式について

コメント受信はKickのWebサイトが利用するリアルタイム接続（Centrifugo）と内部エンドポイントに依存します。Kickの公式公開Webhook/APIではありません。Kick側の仕様変更、アクセス制限、接続方法の変更により、一時的または恒久的に動作しなくなる可能性があります。公式APIと同等の安定性は保証するものではありません。

## Kick API接続設定

Kick公式APIを使った配信状態の自動監視には、Kick Developerで作成したアプリのClient IDとClient Secretが必要です。Client SecretはWindowsの暗号化機能で保護して保存されます。チャットの直接受信だけならClient ID／Client Secretは不要です。

## 開発環境

- Node.js 22以上
- Windows 10/11（デスクトップアプリ）
- Electron、React、TypeScript、Vite

```bash
npm install
npm run dev
```

Windows向けインストーラーを作成する場合：

```bash
npm run dist:win
```

## データ保存

- チャンネル一覧・録画専用一覧・設定：Electronのユーザーデータ領域
- 録画映像・音声：設定画面で指定したフォルダー
- チャット：`Chat/チャンネル名/YYYY-MM-DD.jsonl`
- Client Secret：WindowsのElectron safeStorageで暗号化して保存

## 利用上の注意

録画・チャット保存はKickの利用規約、配信者の権利、プライバシー、適用法令を守って利用してください。配信者の許可を得たうえで利用し、保存したデータを適切に管理してください。
