# Kick Live Message Recorder

Kickの配信を監視・録画し、リアルタイムコメントを保存できるWindowsデスクトップアプリです。録画済み配信・LIVE配信のAI記事生成や、ニコ生風コメント付き動画の作成にも対応しています。

## 主な機能

### 配信監視・録画
- Kickチャンネルの登録・削除、通常チャンネルと録画専用チャンネルの管理
- 配信状態のバックグラウンド監視（最短10秒間隔）
- Windowsログイン時の自動起動・通知領域常駐
- 配信開始時のWindows通知と自動録画
- 手動録画、録画専用チャンネルからの録画
- yt-dlp・FFmpegによる映像／音声の保存と自動結合
- 録画接続が切れた場合の自動再接続
- 録画中のKick公式プレーヤープレビュー
- Kick過去配信（VOD）のURL指定ダウンロード

### コメント取得・保存
- Kickコメントのリアルタイム受信・アプリ内表示
- チャンネル別・日付別のJSONL保存
- 投稿者名・本文・投稿時刻・受信時刻・バッジ・エモート情報の保存
- LIVE配信とVODのコメント履歴取得
- コメントログの検索・確認
- コメント自動取得のON／OFFをチャンネル種別ごとに設定

### ニコ生風コメント付き動画
- 保存済み動画とコメントJSONLを指定して、コメントを動画へ合成
- 白文字・太い黒フチ・影を使ったニコ生風表示
- 右から左へのスクロール、上部固定、下部固定、コメントごとの位置指定
- 長文・短文で画面上の移動速度をそろえ、同じ行での衝突を回避
- 実際のコメントログを使った生成前プレビュー
- フォント・文字サイズ・速度・表示時間・行数・間隔・不透明度を調整
- 元動画と元コメントログを変更せず、別動画として保存

### AI配信記事
- 録画済み配信とLIVE配信の記事生成
- 映像フレーム・音声文字起こし・視聴者コメントを別々の根拠として分析
- AIが情報を照合し、新聞風の見出し・要約・本文・注目ポイントを作成
- LIVE中の記事を段階的に更新し、配信終了時に最終化
- 未登録チャンネルでも、Kickのチャンネル名またはURLを入力して記事だけ生成可能
- Ollama（無料・ローカルAI）とOpenAI APIに対応
- OllamaのVisionモデルとQwen3-ASR音声認識モデルのダウンロード・設定
- 記事の検索、日付別表示、LIVE速報／アーカイブ切替、個別削除

### アプリ更新
- 現在のバージョン・更新確認・ダウンロード進捗の表示
- 起動時・定期的なアップデート確認
- GitHub Releasesからのβ版自動更新
- バージョン更新画面でリリースノートと更新履歴を確認

## 無料AI記事生成（Ollama）

Ollamaを使用すると、OpenAI APIキーやクラウドAIの従量課金なしで、PC内のAIモデルによる記事生成を利用できます。

1. [Ollama公式サイト](https://ollama.com/download)からWindows版をインストールします。
2. アプリの「配信記事」設定でAIエンジンを「Ollama（無料・ローカルAI）」にします。
3. Visionモデルは qwen2.5vl:3b、音声認識モデルは frozenlab/qwen3-asr:0.6b を利用します。
4. アプリ内のモデル導入機能から必要なモデルをダウンロードし、接続テストを実行します。
5. LIVE配信の記事を自動生成する場合は、LIVE自動記事化を有効にします。

初回のモデル取得にはインターネット接続が必要です。モデル実行速度はPCのメモリー・CPU・GPU性能に依存します。Ollamaをローカルで利用する場合、AI処理は設定したローカルOllamaで行います。

OpenAI APIを選択した場合は、設定に応じて配信情報・コメント・代表フレーム・音声文字起こしテキストがAPIへ送信され、利用料が発生する場合があります。

## コメント付き動画の生成

左メニューの「コメント付き動画」から、録画ライブラリの動画と同じチャンネルのコメントJSONLを選択します。LIVE配信が日付をまたいだ場合は、複数日分のログをまとめて指定できます。VODログは個別に選択します。

同期には、VODコメントに保存された配信経過秒数、またはLIVEコメントの投稿時刻と動画開始時刻を使用します。同期ずれは秒単位で調整できます。β51では、新しいLIVE録画のプロセス起動時刻を RecordingMetadata フォルダーへ保存し、実ログプレビューに同期方式と推定開始時刻を表示する改善を開発中です。β51のこの改善はまだ公開版には含まれていません。

## 開発環境

- Windows 10／11（デスクトップアプリ）
- Node.js 22以上
- Electron、React、TypeScript、Vite

    npm install
    npm run dev

    npm run dist:win

## データ保存

設定画面で指定したフォルダーに、主に次のデータを保存します。

- 録画映像・音声：録画保存先
- コメント：Chat/チャンネル名/YYYY-MM-DD.jsonl
- AI記事：Articles/チャンネル名/
- コメント付き動画：CommentVideos/
- LIVE録画の同期用情報（β51開発中）：RecordingMetadata/

チャンネル一覧・設定・認証情報はPC内に保存します。Client SecretはWindowsのElectron safeStorageで暗号化して保存します。

## コメント取得方式について

コメント取得はKickのWebサイトが利用するリアルタイム接続（Centrifugo）と内部エンドポイントに依存します。Kickの公式公開Webhook/APIではありません。Kick側の仕様変更・アクセス制限・接続方式の変更により、動作しなくなる可能性があります。公式APIと同等の安定性は保証しません。

## 利用上の注意

録画・コメント保存はKickの利用規約、配信者の権利、プライバシー、適用法令を守って利用してください。配信者の許可を得たうえで利用し、保存したデータを適切に管理してください。
