# Kick Live Message Recorder

Kick のライブ配信を録画し、チャットを保存する Windows デスクトップアプリです。

## 開発状況

初期プロジェクトの土台を作成中です。現在の画面はUIプレビューであり、Kickへの接続・実録画・チャット取得はまだ実装されていません。

## 目標機能

- 自分の配信・他の配信者の配信を登録して監視
- 配信開始を検知して自動録画、または手動で録画開始・停止
- 映像・音声とチャットを保存
- 配信ごとの録画一覧、チャット検索、CSV/JSONエクスポート
- Windows向けインストーラー

## 技術方針

- Electron + TypeScript
- React + Vite
- SQLite（録画・チャットのメタデータ）
- FFmpeg / yt-dlp（配信映像の取得・保存。導入方法と配信側の仕様を検証しながら実装）
- Kick公式API・公式イベントを優先。非公式の内部エンドポイントに依存する機能は、仕様変更リスクを明示します。

## 開発

```bash
npm install
npm run dev
```

## 注意

録画・チャット保存は、Kickの利用規約、配信者の権利、プライバシー、適用法令を守って利用してください。チャットの保存期間・削除要求への対応を実装予定です。
