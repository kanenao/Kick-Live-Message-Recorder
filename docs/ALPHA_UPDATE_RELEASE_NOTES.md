# Kick Live Message Recorder 0.3.3-alpha.66

Windows 64bit向けα版（開発中のPre-release）です。Kick版録画ライブラリのデザイン・操作性を改善しました。

## Nico版風の録画ライブラリ

- Kick APIから配信者のプロフィール画像・表示名を取得し、配信者カードで丸いアイコンとして表示します。録画済みの未登録チャンネルも取得対象です。
- 画像取得不可・API認証なしの場合は文字アイコンへ切り替え、保存済みの動画・コメントへのアクセスは継続します。
- 配信者カードで録画・コメントの情報を整理し、配信別セッションに動画、コメント、AI記事の見出しと要約を表示します。
- 各JSONLコメントログに「コメントを見る」「開く」「場所」操作を追加。選択したログの直近100件だけを表示し、同じ配信者の他の日付・VODのコメントを混ぜません。
- AI記事付き配信の件数表示と、記事のある録画だけを探せる絞り込みを追加しました。

## データ保護・互換性

- 0.3.2-alpha.65で追加した削除済み動画・コメントの自動同期機能を維持します。AI記事と履歴JSONを勝手に削除しません。
- 過去のLIVEコメントは日付単位で保存されている場合があり、配信への紐付けが確実でないログには注意表示を維持します。
- プロフィール画像の取得にはKick API認証・ネット接続が必要です。画像が取得できなくても録画ライブラリは利用できます。
- 旧β版・α版向けの更新チャンネル（beta.yml / alpha.yml / latest.yml）互換配布を継続します。
- 実際のWindows環境での表示確認と長時間録画は引き続き検証が必要です。
