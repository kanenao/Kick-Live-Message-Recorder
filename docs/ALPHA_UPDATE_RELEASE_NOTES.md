# Kick Live Message Recorder 0.7.1-alpha.81

Nico版を参考に、Kickの「コメント付き動画を生成」に**実際の動画再生とコメントのリアルタイム重ね描き**を追加したWindows x64向けα版です。

- **本物の映像プレビュー**：録画動画を再生しながら、その再生時刻に対応したコメントが動画上を流れます。停止・シーク・再生に同期します。
- **設定を即時反映**：フォント・文字サイズ・速度・固定位置・表示行数・重なり間隔・透明度・投稿者名を変更すると、プレビューも更新します。
- **長時間配信へ対応**：コメントログを全時間帯から最大1200件抜粋してプレビュー。従来の簡易見本プレビューも引き続き利用できます。
- **安全なファイル選択**：元動画を選んだ後、プレビュー用のファイル選択でも同じ動画を選んでください。別の動画を誤って重ねないよう、ファイル名を確認します。
- **元データ保護**：再生・シーク・設定調整では動画・JSONL・ASS・AI記事を変更しません。プレビュー用の一時URLも解放します。

プレビューはASS本書き出しの近似表示であり、エンコーダーの描画結果と完全一致するものではありません。MP4・WebMなどChromiumが再生できる形式をご利用ください。Windows実機での一部形式・長時間配信については引き続き動作確認が必要です。
