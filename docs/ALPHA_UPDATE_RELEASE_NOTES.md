# Kick Live Message Recorder 0.7.4-alpha.84

**新しいKick Live Message Recorder専用アイコンを採用したWindows x64向けα版です。**

- **正式アプリアイコン**：緑と黒のKロゴに、LIVE／赤いREC／コメントのマークを組み合わせたデザインに更新。
- **Windows全体を統一**：EXE・セットアップウィザード・スタートメニュー・デスクトップショートカット・タスクバー・アプリのウィンドウに新しいアイコンを設定。
- **通知領域も統一**：24時間監視のトレイアイコンを新デザインに更新。既存の監視処理は維持。
- **アプリ画面でも採用**：左のサイドバーとヘッダーのブランドアイコン、ブラウザープレビューのfaviconも新デザインを使用。
- **品質**：ビルド時に正式画像からPNGとICOを自動生成し、SHA-256とWindows ICOヘッダーを自動検証。
- **元データ保護**：録画・コメント・記事・字幕・設定は変更しません。

Windowsではショートカットやタスクバーの古いアイコンがキャッシュされていることがあります。新しいアイコンが表示されない場合はアプリを終了して再起動し、必要ならショートカットを作り直してください。
