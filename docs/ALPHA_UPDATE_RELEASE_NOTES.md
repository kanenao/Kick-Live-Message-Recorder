# Kick Live Message Recorder 0.3.1-alpha.64

**Windows x64向けα版**（Pre-release）です。最新の録画安定化改善は0.3.0-alpha.63から継続します。

## 旧β版・α版の更新経路を統一

- 配布先の更新情報を `alpha.yml`、`beta.yml`、`latest.yml` の3形式で用意します。3つは同じ検証済みWindowsインストーラーを参照し、旧β版・旧α版が参照する更新チャンネルとの互換性を改善します。
- アプリ起動時と約6時間ごとに更新を確認し、利用可能な新しいα版を自動ダウンロードします。Windowsインストーラー版では、アプリ終了時または更新画面の「再起動して更新」から適用できます。
- 録画・VODダウンロード中に「再起動して更新」を実行した場合、録画中断を防ぐため更新を保留します。
- 公開前にマニフェストのバージョン一致・同一内容・インストーラーサイズとハッシュを検証します。
- 旧版から更新できない場合のGitHub Releasesへの案内を改善しました。

## ご注意

- 過去にインストールされたプログラム自身の更新機構を後から改変することはできません。旧版に更新機能がない・壊れている・通信環境でGitHubに接続できない場合は、最新α版インストーラーを一度だけ手動でインストールしてください。
- ZIP版・開発版・ブラウザープレビューはアプリ内自動更新の対象外です。
- 将来の正式版（安定チャンネル）に開発中α版を自動配信する機能ではありません。正式版の配信経路は別途整備します。
- 通信環境やWindowsのインストール権限、旧版固有の更新実装によっては移行できない場合があります。旧β版を含む全インストール環境での成功を保証するものではありません。
- 大切な録画中はアプリ終了やWindows再起動を避けてください。
