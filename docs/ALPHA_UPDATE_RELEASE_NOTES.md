# Kick Live Message Recorder 0.8.0-alpha.86

**LIVE配信AI新聞の映像解析範囲を、配信全体へ広げる開発中のα版です。**

- **長時間LIVEの映像サンプリング**：直近8枚だけをAIへ送る方式をやめ、配信全体から均等に選ぶ最大7枚の履歴サンプル＋最新フレームを使います。
- **再接続後も履歴を維持**：映像キャプチャが一時的に切断して再接続した場合も、配信セッション内の代表フレーム履歴を引き継ぎます。
- **解析範囲を正確に表示**：記事画面でAIに送った代表フレーム数と、実際にキャプチャした累計枚数を分けて表示します。
- **メモリ保護**：AI解析用JPEGの保持は最大8枚。長時間配信でも画像を無制限に蓄積しません。
- **AI応答エラーの自動復旧**：Ollama／OpenAIの一時的な接続エラーを最大2回再試行。認証やモデル設定など、再試行で直らないエラーは区別して表示します。
- **未解析データの保護**：AIへ送信中のコメント最大2,000件と文字起こし済み音声区間最大80件を記事JSONへ保存。失敗・アプリ再起動後も記事の再解析操作から再利用できます。
- **音声の最終処理**：配信終了時にも音声認識の一時エラーを再試行。期限内に処理できない区間は件数とともに警告し、録画があれば元動画から再取得できるよう案内します。
- **アーカイブ再解析**：保存済み記事の新しい映像フレームをVisionモデルへ再送信し、未解析コメント・音声の保存分も再利用します。
- **記事画面**：AIに送った代表フレーム数・取得累計、未解析コメント・音声区間数を分けて表示。
- **既存データ保護**：録画動画、KickチャットJSONL、ASS字幕、既存の記事JSONは自動変更・削除しません。

本版は開発中です。自動回帰テスト、型チェック、Windows x64ビルドを実行してから公開します。実際のKick LIVE配信での長時間動作確認は別途必要です。
