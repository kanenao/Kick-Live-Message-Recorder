# Kick Live Message Recorder 0.3.4-alpha.67

Windows 64bit向け開発中α版（Pre-release）です。

## Kick動画・コメントの保存ファイル名を改善

- 今後録画するLIVE動画と、そのLIVEコメントJSONLを配信者表示名と配信開始日時を含むファイル名で保存します。Kickアカウントのチャンネル名も付け、表示名の変更後も録画ライブラリで分類できます。
- 例：`だいぶつ__daibututv2__2026-11-16_20-54-47__LIVE.mp4` と `だいぶつ__daibututv2__2026-11-16_20-54-47__LIVE.jsonl`。
- 過去配信（VOD）動画はKick APIから取得した元配信日時・配信者名・動画IDで命名。VODコメントのJSONL/TXT/ASSにも同じ日時・IDを使用します。
- 配信開始日時を取得できないLIVEは録画・コメント取得の開始時刻を共通で使用します。VODの配信日時が取得できない場合は、ダウンロード日付を配信日付として扱わず `date-unknown` を表示します。
- ファイル名に使えないWindows予約文字を自動的に置き換えます。既存ファイルとの衝突を防ぎ、再録画は `_take2`、LIVE再接続は `_retry02` などを付けます。
- 録画ライブラリとコメント付き動画生成は新形式を識別します。**過去の動画・コメントファイルは勝手にリネーム・移動・削除しません**。

## データ保護と注意点

- 日本語版Windowsではファイル名の日付・時刻はPCのローカル時刻（日本標準時）です。PCのタイムゾーン設定が異なる場合は現地時刻になります。
- Kick APIが利用できない場合は配信者表示名の代わりにチャンネル名を使用します。
- 既存の録画とコメントを任意にエクスプローラーで改名すると、録画ライブラリや記事の関連付けが崩れる恐れがあります。
- 過去のLIVE日別コメントJSONLも旧形式で閲覧可能です。新形式への自動変換は行いません。
- 実際のKickライブ・長時間録画の動作はWindows実機での追加検証が必要です。
- 自動更新用の `alpha.yml`・`beta.yml`・`latest.yml` を引き続き公開します。
