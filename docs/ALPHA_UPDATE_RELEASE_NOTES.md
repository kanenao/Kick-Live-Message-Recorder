# Kick Live Message Recorder 0.7.3-alpha.83

コメント付き動画の**リアルタイムプレビュー**で、長時間配信のコメントが時刻どおりに見えるよう改善したWindows x64向けα版です。

- **動画の全時間帯に対応**：投稿が一部に集中した2時間以上の配信でも、冒頭・途中・終盤のコメントを動画の時刻に分けて抜粋。最大1,200件の表示候補をバランスよく選びます。
- **コメントの時刻ずれを改善**：同時投稿で表示行が足りない場合、古いコメントを何分も遅らせて表示せず、過密な一部のサンプルは省略します。
- **Nico風プレビューは継続**：実動画の再生・停止・シーク、文字サイズ・速度・行数・位置・透明度などの調整は引き続き利用できます。
- **元データは保護**：録画動画・JSONLコメント・ASS・AI記事には変更を加えません。今回の改良は画面上のプレビューに限定され、ASS書き出し結果は変わりません。
- **回帰テスト**：冒頭に2万件以上のコメント、終盤に少数のコメント、投稿集中による描画遅延を再現して検証します。

Windows実機での特殊な動画形式と長時間再生については、引き続き動作確認が必要です。
