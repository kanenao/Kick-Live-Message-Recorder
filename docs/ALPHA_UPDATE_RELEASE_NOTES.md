# Kick Live Message Recorder 0.6.0-alpha.78

映像・音声・コメントを活用する配信AI新聞と、LIVEコメントの長時間受信の安定性を強化するWindows x64向けα版です。

- **配信AI新聞の時刻別根拠**：実際に取得できた視聴者コメント、音声文字起こし、映像の代表フレームを、放送開始からの時刻付きで確認できるようにしました。映像フレームの取得とAIによる内容分析は区別します。
- **長時間VODの音声解析**：従来の先頭2時間制限を改善。2時間を超える配信では、序盤から終盤まで最大48か所・各45秒の音声を抜粋し、ローカルOllamaで文字起こしします。抜粋した部分だけが解析済みであることを明示します。
- **AI記事本文の復元**：分割JSONや構造化された文章への対応を強化し、AI内部のreasoningやanalysisを記事本文と取り違えないようにしました。
- **コメント保存失敗時の継続性**：ディスク容量不足・書き込み権限エラーなどでJSONL保存に失敗しても、コメント受信自体が停止しないよう修正し、受信画面へ保存エラーと復旧を表示します。
- **巨大コメントログの表示高速化**：最近のコメント表示でログファイル全体を読み込まず、各JSONLの末尾最大512KiBのみを参照します。壊れた行や不正な日時を安全に無視します。
- **自動回帰テスト**：保存失敗・巨大ログ・長時間音声の抽出範囲・AI記事の根拠などの検証を追加しました。

既存の動画・コメントJSONL・ASS・記事を自動削除・変更しません。安定版ではなくα版です。Kickの実LIVEやWindows環境、ローカルOllamaモデルを使った個別の動作確認は引き続き必要です。
