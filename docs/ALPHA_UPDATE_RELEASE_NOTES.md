# Kick Live Message Recorder 0.6.1-alpha.79

配信AI新聞で同じ映像説明・映画紹介が何度も表示される不具合を修正したWindows x64向けα版です。

- **映像説明の繰り返し防止**：AIが同じ文章を繰り返す場合、要約内、場面リスト内、要約と場面リストの間で重複した文章をまとめます。
- **記事本文・注目ポイントも改善**：同じ記事段落や長い文の繰り返しを減らし、異なる情報は残します。
- **すでに保存した記事も対象**：画面表示時にも重複を抑制します。過去の動画・音声・コメント・記事JSON・ASS字幕は書き換えません。
- **テスト強化**：映画の説明が何度も返るAI応答を再現した回帰テストを追加し、型チェック・ビルドを確認します。

このα版は開発中のテスト版です。実際のKick配信・Windows・Ollamaのすべての組み合わせでの動作を保証するものではありません。
