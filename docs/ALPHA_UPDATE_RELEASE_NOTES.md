# Kick Live Message Recorder 0.3.7-alpha.70

Windows 64bit向けのα版（Pre-release）です。

## 録画ライブラリからコメントファイルを削除できるように改善

- 配信者の録画ライブラリ → 「配信一覧を見る」 → 対象放送の「ファイル・コメント」を開くと、保存されたJSONLコメントファイルに**「削除」ボタン**が表示されます。
- 削除ボタンを押すとファイル名を含む確認画面を出します。確認すると選んだJSONLのみをWindowsの**ごみ箱へ移動**します。
- 動画MP4、AI記事、別のコメントファイル、TXT/ASS字幕は同時削除しません。
- 削除後、録画ライブラリのファイル数・コメント数・配信別表示を即時更新し、開いていたコメントプレビューを閉じます。
- コメント付き動画生成で選択していたログが削除された場合、その選択からも外します。
- LIVEコメントを書き込み中のファイルと、VODコメント取得処理中の削除を禁止します。
- 保存先の `Chat/<Kickチャンネル名>/<ファイル名>.jsonl` の通常ファイル以外は削除できません。パスの改ざんやシンボリックリンクなどは拒否します。

## データ保護

- 誤って削除してしまったJSONLは、Windowsのごみ箱から復元できます（ごみ箱の設定により挙動が異なる場合があります）。
- 既存の録画動画・コメントのTXT/ASS・AI記事は自動削除・改名・移動しません。
- Windows実機の削除動作は追加の検証が必要です。GitHub Actionsのテストとインストーラー検証は実施します。
- 旧β版・α版への更新互換チャンネル（`alpha.yml`、`beta.yml`、`latest.yml`）は継続公開します。
