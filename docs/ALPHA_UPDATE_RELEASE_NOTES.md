# Kick Live Message Recorder 0.8.1-alpha.87

**録画ライブラリと配信AI新聞の動画プレビューが、認識済み録画フォルダーだけを扱うよう改善したWindows x64向けα版です。**

- **配信者別フォルダーを正式対応**：LIVE録画、過去配信、生成コメント付き動画のサムネイルおよび時刻別場面プレビューは、`Recordings/<配信者ID>/` と `CommentVideos/<配信者ID>/` から利用できます。
- **旧動画の互換性**：保存先直下の旧録画と旧 `CommentVideos/` の生成動画も、移動せずに引き続き表示できます。
- **データ安全性**：`Chat/`、メタデータ、知らない階層、外部に出るフォルダーリンクは動画プレビューの対象外です。
- **表示負荷の削減**：配信者一覧の全件スキャンをせず、選択した動画の親フォルダーだけ検証します。
- **既存の機能は維持**：録画、チャット保存、ASS生成、AI新聞の映像・音声解析は変更しません。
- **テスト**：新旧フォルダーと無関係なフォルダーの回帰テスト・型チェック・Windowsビルドを検証します。

Windows実機での長時間録画と一部動画形式は引き続き検証が必要です。
