# Kick Live Message Recorder 0.4.2-alpha.75

Windows 64bit α版（Pre-release）。

## 保存済みVODコメントからASSを再生成

- 過去配信のコメントを取得済みなら、Chatフォルダー内のVOD JSONLを選び、インターネット接続なしでASSを再出力できます。
- 速度・入り方のニコ生風自動調整、手動調整、emote除去設定が反映されます。
- 出力ファイル名は `_nico-auto.ass` または `_nico-manual.ass`。既存ファイルがあれば連番で保存し、元JSONL・TXT・既存ASSを上書きしません。
- コメント件数、字幕に採用された件数、省略件数、保存先を表示します。
- JSONLには配信終了時刻がないため、ASSの計算用の最大時刻は最後のコメント＋30秒です。

## 安全性

- アプリのChat配下でチャンネル別に保存されたVOD JSONLのみを受け付けます。
- 不正パス、シンボリックリンク、異常なログ、巨大ファイル、ソースの処理中変更を検知します。
- 元動画、AI配信記事、既存のコメントファイルには変更を加えません。
