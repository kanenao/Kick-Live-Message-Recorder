# Kick Live Message Recorder 0.4.1-alpha.74

Windows 64bit向けのα版（Pre-release）です。

## ニコ生風ASS字幕の自動速度・進入調整

- 過去配信のASSとコメント付き動画のASSに、自動調整を追加。初期状態はONです。
- コメントの長さ・直近の投稿密度から1件ごとに速度と画面右端からの入り方を計算します。
- 後続コメントが先行コメントを追い越さないよう速度差と文字幅を計算し、空き行に自動配置します。
- 混雑時は最大1.2秒だけ入場タイミングをずらして重なりを防止します。全行が埋まっている時は一部のコメントを省略します。
- OFFで従来の手動横断時間・速度・行数・コメント間隔に戻せます。
- 元のJSONL・TXT、動画、配信記事データは変更しません。
