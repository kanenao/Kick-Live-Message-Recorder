# Kick Live Message Recorder 0.7.0-alpha.80

録画ライブラリと配信AI新聞に、動画の時刻付き場面サムネイルを表示する新機能を追加したWindows x64向けα版です。

- **放送画面の場面一覧**：ニコ生 AI 新聞の見せ方を参考に、左側に大きい代表画像、右側に複数の時間付きサムネイルを配置。画像を選ぶと代表画像が切り替わります。
- **録画ライブラリ**：配信のサムネイルと各動画の「場面一覧」からプレビューを開けます。再生、保存先、削除など既存の操作も引き続き利用できます。
- **配信AI新聞**：記事上部の放送画面から同じプレビューを開けます。AIによる映像理解と、動画から取得した実際の画像は混同しません。
- **長時間動画とキャッシュ**：最大30件の場面を全時間帯から抽出し、アプリ内キャッシュで次回表示を軽くします。FFmpeg/FFprobeが必要で、抽出に時間がかかる動画もあります。
- **元データ保護**：録画中・削除済み・ライブラリ外の動画は拒否します。元動画・コメント・記事・字幕を自動変更しません。
- **表示の注意**：時刻を選ぶ操作は代表画像の切替です。元動画を開くボタンは既定のプレーヤーで通常再生を開始します。

α版のためWindows実機での長時間配信・一部動画形式は引き続き動作確認が必要です。
