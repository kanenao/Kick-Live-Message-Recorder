# Kick Live Message Recorder 0.5.0-alpha.76

Windows 64bit向けα版（Pre-release）。

## 配信AI新聞のフル強化

- 監視に登録されていなくても、録画ライブラリに保存された配信者の動画からAI記事を生成できます。
- コメントログは「同じ配信者の全ログ」ではなく、録画と一致する放送のJSONLだけを自動選択。手動追加・除外が可能です。
- すでに保存した記事には「映像・音声・コメントでAI再解析」を追加。Ollamaのモデルや音声認識設定の変更後に再試行できます。
- モデルがVision入力の映像要約だけを返さない場合、コメント・音声などからできた本文は保持し、映像未解析として警告します。
- アーカイブの再解析後も録画の本来の配信時間を保持。録画進行中は記事を作成する前にブロックします。

## 既存仕様の保持

- Ollamaによる無料ローカル記事生成、VisionモデルとQwen音声認識、LIVE記事の更新は引き続き使用できます。
- 元の録画・コメントJSONL/TXT・記事に紐づくデータは自動削除しません。
- 実際のAIモデルの出力は環境に左右されるため、未解析の情報源やエラーを記事内で確認できます。
