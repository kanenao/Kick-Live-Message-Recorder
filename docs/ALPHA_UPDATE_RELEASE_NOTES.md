# Kick Live Message Recorder 0.7.5-alpha.85

**Kick Live Message Recorder 正式アプリアイコンのWindowsインストール版表示を修正したα版です。**

- 緑・黒のK／LIVE／REC／コメントアイコンをWindows EXE、デスクトップ・スタートメニューショートカット、通知領域、アプリのサイドバー・ヘッダーに採用。
- α84で導入したアイコンのうち、Electronのfile://で表示するアプリ内のPNG参照を相対パスに修正。インストール版でも同じ画像を表示できます。
- 元画像のSHA-256、ICO形式、画面・faviconの相対パスを自動テストし、Windowsインストーラーに含める画像データを検証します。
- 元の録画動画・チャットログ・ASS字幕・AI記事・アプリ設定を変更しません。

Windowsではショートカットやタスクバーの画像がキャッシュされる場合があります。更新後も古い画像が表示される場合はアプリを完全終了して再起動してください。
