# Kick Live Message Recorder 0.3.9-alpha.72

Windows 64bit向けのα版（Pre-release）です。

## 配信記事メニューの不要な文字を修正

- 「配信記事」の上に `\\n` と表示される不具合を修正しました。
- メニュー間の誤った改行表記を正しい改行に戻し、スタイルシートの不要文字も整理しました。
- 表示の回帰テストを追加し、同じ不具合の再発を防止します。

## データ保護

- 保存済みのAI記事・録画動画・コメント・ASS字幕は変更しません。
- α版の公開前にテスト、Windowsインストーラー、更新ファイルの整合性を検証します。
