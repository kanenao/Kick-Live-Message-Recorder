# Kick Live Message Recorder 0.3.2-alpha.65

Windows x64向け開発中α版（Pre-release）です。

## 録画ライブラリの削除済みファイル表示を修正

- 保存先フォルダーから動画ファイルとコメントJSONLの両方を削除したとき、履歴メタデータが残っていても空の番組カードを録画ライブラリに表示しません。
- 録画ライブラリを開いている間は10秒ごと、アプリへ戻った際にも保存先を再読み込みし、エクスプローラーでの外部削除・移動を表示に反映します。
- アプリ内から動画を削除した場合も配信別一覧を直ちに更新します。コメントファイルが残っている場合は、コメントのみの記録として表示を維持します。
- 対象のコメントログがなくなった際は、古いコメント詳細表示を閉じます。
- 既存の録画ファイル、コメントログ、履歴JSON、AI記事JSONを**自動削除する変更ではありません**。AI記事だけが残る場合、録画ライブラリには表示せず、AI記事一覧で引き続き管理できます。
- 元ファイルを実際に作成して削除する回帰テストと、録画・コメント一覧の自動更新テストを追加しました。

## 引き継いだ機能

- LIVE録画の途中切断からの自動再接続、録画専用チャンネルの複数VODダウンロード、録画ライブラリの配信別カード表示。
- α版、旧β版、旧クライアントの更新互換ファイル（`alpha.yml`・`beta.yml`・`latest.yml`）を引き続き同時配布します。
- 更新の適用は録画やVODのダウンロードが終わってから行ってください。

## 注意

- 外部削除の反映は最大約10秒（画面が表示中の場合）か、アプリへ戻った際の再読込です。
- エクスプローラーから移動・削除した動画の復元や、ごみ箱の復旧を行う機能ではありません。
- データ保存先が変わった場合はアプリ設定の保存先を確認してください。
- Windows実機での長時間録画の完全な動作保証ではなく、α版として提供します。
