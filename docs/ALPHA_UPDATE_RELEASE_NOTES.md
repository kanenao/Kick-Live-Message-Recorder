# Kick Live Message Recorder 0.4.0-alpha.73

Windows 64bit向けα版（Pre-release）です。

## 過去配信ASS字幕をニコ生風に細かく調整

- コメントが画面を横切る基準時間（2〜15秒）と流れる速度（50〜200%）を変更可能にしました。
- 画面右端からの進入余白（0〜300px）を指定し、右から左へ入るタイミングを調整できます。
- 投稿時刻との同期ずれ（-10〜+10秒）、表示行数（1〜18）、同じ行の最小間隔（0〜200px）を設定できます。
- コメントが集中した際、埋まっている行に無理に重ねる処理を廃止しました。
- 設定保存とニコ生風のおすすめ設定へ戻すボタンに対応します。

## データ保護

- 変更対象は過去配信コメントのASS出力です。元のJSONL・TXT、動画録画、配信AI記事は変更しません。
- 「コメント付き動画を生成」側の速度、文字、上下固定等の設定は従来どおり利用できます。
- 自動テスト・型チェック・Windowsビルド・配布ファイル整合性を確認した場合に公開します。
