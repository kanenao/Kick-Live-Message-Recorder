# Kick Live Message Recorder 0.3.6-alpha.69

Windows 64bit向けα版（Pre-release）です。

## 録画ライブラリでKickの配信者ページを開く

- 録画ライブラリの配信者アイコンをクリック・タッチすると、その人のKick公式ユーザーページをWindowsの既定ブラウザーで開きます。
- 配信者の**名前**からも同じページへアクセスできます。
- Kickプロフィール画像が取得できない配信者も、表示されたイニシャルアイコンをクリックして公式ページを開けます。
- 配信者の表示名が日本語であったり変更されても、Kickのチャンネル名からURLを生成するため、同じチャンネルへ移動できます。
- タッチパネルやキーボード（Tabで選択しEnter/Spaceで実行）に対応。クリック可能な状態・フォーカス表示を改善しました。
- アプリは既定ブラウザーを開くだけで、録画ライブラリの一覧・保存済みデータはそのまま表示されます。
- リンク先は必ず `https://kick.com/チャンネル名` とし、不正な入力・外部ドメインへのリダイレクトを拒否します。

## データ保護と注意

- 録画動画・コメント・AI記事・サムネイルのファイルを編集・移動・削除しません。
- Kick上でチャンネルが削除・改名された場合、元の名前から開いたページが見つからない可能性があります。
- Windows実機での外部ブラウザー起動は追加の動作確認が必要です。URL検証とアプリビルドはGitHub Actionsでテストします。
- `alpha.yml`、`beta.yml`、`latest.yml` の更新互換チャンネルを引き続き公開します。
