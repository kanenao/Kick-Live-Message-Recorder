# Kick Live Message Recorder 0.7.2-alpha.82

録画ライブラリのファイルを配信者別に整理して保存するWindows x64向けα版です。

- **LIVE・過去配信**：新しく録画するファイルを `Recordings/<チャンネルID>/` に自動保存。録画の開始日時・放送名など従来のファイル名も維持します。
- **コメント付き動画**：生成したMP4・ASSを `CommentVideos/<チャンネルID>/` に保存。
- **チャットログ**：従来どおり `Chat/<チャンネルID>/` に保存。LIVEと過去配信のコメントは混在しないよう既存形式を維持。
- **録画ライブラリ**：新旧の保存先を同時にスキャンするため、旧版で保存した動画も表示されます。配信者ごとに「保存先を開く」ボタンを追加。
- **元データ保護**：録画・コメント・ASS・AI記事・メタデータを勝手に移動・削除・改名しません。安全でないフォルダーや保存先外のファイルを無視します。
- **検証**：配信者別・旧フォルダー互換・コメント付き動画・VOD・録画削除の回帰テストを追加。

配信者ごとのフォルダーはKickの安定したチャンネルslugで構成し、表示名が変わっても同じ配信者の録画が分かれないようにします。Windows実機での長時間録画・一部動画形式は引き続き動作確認が必要です。
