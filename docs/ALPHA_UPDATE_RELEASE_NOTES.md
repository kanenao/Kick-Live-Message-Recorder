# Kick Live Message Recorder 0.3.5-alpha.68

Windows 64bit向けの開発中α版（Pre-release）です。

## 録画ライブラリの画面をコンパクトに改善

- 配信ごとの大きな画像・文章のカードを廃止し、**約75pxのコンパクトな一覧**にしました。
- 配信ごとにサムネイル、LIVE/VOD、タイトル、日時、動画・コメントの件数、再生ボタンを横に配置。
- 「ファイル・コメント」で個別に詳細を開くと、録画ファイル、コメントJSONL、AI記事を閲覧できます。
- 大きな一覧の内側のスクロールをやめ、配信者を開いても画面全体で縦方向にスクロールできます。
- 画面幅に応じてサムネイルと操作ボタンを小さくする表示調整を行いました。

## 録画した動画の映像からサムネイルを生成

- 番組の代表画像として、保存済み動画の約1秒地点のフレームをFFmpegで抽出し、320x180のJPEGサムネイルにします。
- サムネイル画像はアプリ専用キャッシュへ保存し、録画動画・コメント・記事は改変しません。
- 配信が画面に入った時だけ画像生成を要求するため、多数の録画があっても一度に無制限の処理を行わない構成です。
- 動画を保存していない配信、録画中のファイル、破損動画、FFmpegが見つからないときは従来のプレースホルダーを表示します。
- キャッシュは古いファイルから整理し、録画保存先外へのアクセスとシンボリックリンクの脱出を拒否します。

## 注意

- Windows実機で、すべての録画形式のフレーム抽出が成功することまでは保証していません。映像形式によってはサムネイルを生成できない場合があります。
- サムネイルの表示は動画を読み込んでから行われ、初回は多少時間がかかる場合があります。
- 既存の録画・コメント・AI記事のファイルは一括リネーム・移動・削除しません。
- 更新時には録画・VODダウンロードが終了していることを確認してください。
- `alpha.yml`、`beta.yml`、`latest.yml` の更新互換チャンネルを引き続き公開します。
