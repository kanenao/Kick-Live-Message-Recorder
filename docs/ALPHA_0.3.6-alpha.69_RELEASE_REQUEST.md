# Kick Live Message Recorder 0.3.6-alpha.69 公開指示

要望：録画ライブラリのKick配信者アイコンをタッチすると、その配信者のKickユーザーページが開く仕様。

対応：配信者アイコンと名前をクリック可能にする。Windows既定ブラウザーでKick公式ページを開く。URLを厳密に検証し、録画・コメント・AI記事・サムネイルファイルは変更しない。

公開条件：型チェック・ユーザーリンク検証テスト・アプリビルド・Windowsインストーラー作成・配布ファイル名とalpha.yml/beta.yml/latest.ymlのURL・SHA512検証がすべて成功すること。α版だけをPre-releaseとして公開。
