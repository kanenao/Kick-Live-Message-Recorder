# 追っかけ録画（β版実験機能）

手動LIVE録画で選択時のみ、yt-dlpのHLSダウンローダーをFFmpegに指定し、入力オプション `-live_start_index 0` を使います。配信サーバーが公開しているHLSプレイリストの最古セグメントからの取得を試みます。Kickはyt-dlpの汎用 `--live-from-start` の対応サイトではなく、放送開始から全編が取得できる保証はありません。

- 通常の手動録画・自動録画・VODは従来の動作を維持します。
- 再接続時は通常録画とし、過去の区間を繰り返し取得しません。別ファイルに保存し、自動連結はしません。
- 初回ファイルは `_chase` を付けます。実映像の開始時刻が不明なので録画プロセス起動時刻を同期基準として保存しません。コメント付き動画の開始時刻はファイル終端からの推定となり、手動調整が必要な場合があります。過去コメントは自動取得しません。
- LIVE終了一後に配信全編のVODが公開される場合は、既存の過去配信ダウンロードから取得できます。自動VOD補完・完全結合は未実装です。
- Windows実機のKick LIVEで追っかけ範囲・接続継続・停止後の再生・コメント同期を確認するまで実験機能です。

参考: https://ffmpeg.org/ffmpeg-formats.html#hls-1 / https://github.com/yt-dlp/yt-dlp#video-selection
