# Kick Recorder 0.1.0-beta.3

## 今回の更新

- アプリ画面の英語ラベルを日本語に統一
- Windowsインストーラーの表示言語を日本語に設定
- 現在のバージョン番号を画面内に表示
- 起動時・6時間ごとの自動更新確認を追加
- 新しいバージョンを自動ダウンロード
- アプリ終了時の更新適用と、設定画面からの再起動更新に対応
- GitHub Releasesへのβ版公開ワークフローを追加

## ご注意

- 0.1.0-beta.2以前には自動更新機能が含まれないため、0.1.0-beta.3は手動でインストールしてください。
- 自動更新はWindows 64bit版が対象です。
- 現在の配布ファイルはコード署名されていません。HTTPSとファイルハッシュでダウンロード内容を検証しますが、発行元のWindows署名検証は行いません。
- Kick配信の実録画・チャット保存機能は引き続き開発中です。
