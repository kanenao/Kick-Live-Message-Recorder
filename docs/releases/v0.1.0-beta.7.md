# β版 0.1.0-beta.7

## アプリ名を変更

- 表示名を「Kick Recorder」から「Kick Live Message Recorder」に統一
- ダッシュボードのブランド表示・フッター・HTMLタイトルを更新
- Windowsウィンドウタイトル、通知、上部メニュー、バージョン情報の名前を更新
- Windowsインストーラー・デスクトップ/スタートメニューのショートカット名を更新
- 既存バージョンからの自動更新とユーザーデータ引き継ぎを維持するため、内部App IDとユーザーデータ保存先IDは変更していません

## 録画機能

β6の録画機能（yt-dlpによる手動/自動録画、録画停止、上限付き再接続）を引き継ぎます。

## 注意事項

- yt-dlp.exeとFFmpegは別途用意して設定してください。
- Kickの実配信録画とWindows上での自動更新適用は、利用環境で確認してください。
- チャット保存と録画ライブラリは引き続き開発中です。
