# β版 0.1.0-beta.6

## 録画機能の初期実装

- yt-dlp.exeを外部指定してKick配信を録画する処理を追加
- ダッシュボードのチャンネル行から手動録画の開始・停止
- 自動録画モードのチャンネルは、監視でOFFLINEからLIVEへの変化を検出したとき自動開始
- 録画中・再接続中・停止中・エラーの状態と進捗を画面に表示
- ネットワーク異常終了時に5秒待機して再接続を試行（最大5回）
- FFmpeg実行ファイルの任意指定
- 保存先配下にチャンネルごとのフォルダーを作成し、日付・配信タイトル・IDを含むファイル名で保存

## セットアップ

1. yt-dlp公式ReleasesからWindows用 `yt-dlp.exe` を取得
2. FFmpegをPATHに追加するか、`ffmpeg.exe` を別途取得
3. アプリの「設定」→「録画エンジン」で実行ファイルを指定
4. 保存先を設定し、配信中のチャンネルで録画を開始

公式配布元:
- https://github.com/yt-dlp/yt-dlp/releases
- https://ffmpeg.org/download.html

## 制限・未実装項目

- yt-dlp/FFmpegはインストーラーに同梱しません。利用者が公式配布元から取得して指定してください。
- Kickの配信抽出はyt-dlpの対応状況に依存します。Kick側の仕様変更で動かなくなる場合があります。
- 録画開始以前の映像は取得しません。配信が正常終了すると録画処理も終了します。
- チャット取得・時刻同期・録画ライブラリ・保存容量監視・ディスク不足時の自動停止は未実装です。
- 自動録画はアプリ起動中の監視でOFFLINE→LIVEを検出した場合に開始します。アプリ起動時点ですでに配信中のチャンネルを初回検出で自動録画する処理は行いません。
- Windows実機での実配信録画テストは未完了です。CIで型チェックとビルドを確認した後、実配信で別途確認が必要です。
