# β版 0.1.0-beta.8

## コメント付き動画の生成

- 録画済み動画とコメントファイルを選び、コメントを映像に焼き込んだMP4を生成
- NicoConvAssなどで作成したASS字幕を元の位置・スタイルのまま合成
- JSON / CSV / XML / TXT / SRTログを読み込み、ニコニコ生放送風の横スクロールコメントに変換
- ニコ生形式のXML `vpos`（1/100秒）に対応
- コメントのフォントサイズ・流れる速さ・投稿者名の表示・上/下固定コメント・時刻補正（±3600秒）を設定
- 読み込み形式とコメント件数を事前表示
- FFmpegのエンコード進捗を表示し、生成中のキャンセルに対応
- 生成途中のファイルは一時ファイルとして作成し、完了時のみ出力先へ置き換え
- 既存の出力ファイルがある場合は生成完了までバックアップし、失敗時は元ファイルを復元

## 使い方

1. 「コメント付き動画」タブを開き、元動画を選択
2. コメントログ（JSON/CSV/XML/TXT/SRT）またはASS字幕を選択
3. コメント件数・形式を確認して出力先MP4を指定
4. 表示サイズ・速度などを調整して「コメント付き動画を生成」

## 必要なもの

- FFmpeg（ASS/libassフィルターを含むビルド）
- FFmpegは設定画面で実行ファイルを指定するか、Windows PATHへ登録

## 現時点の制限

- Kickのチャット自動取得はまだ未実装です。現時点では、外部ツール等で保存したコメントファイルを読み込んで合成します。
- 動画の時刻とコメントログの時刻（相対秒）が一致している必要があります。
- ISO形式の絶対日時しか含まれないログは、この版では直接同期できません。
- 実配信・長時間ファイルを使用したWindows実機のエンコード検証は未完了です。
