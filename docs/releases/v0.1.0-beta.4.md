# Kick Recorder 0.1.0-beta.4 リリースノート

## 今回の変更

- Kick公式APIを使用した登録チャンネルの自動監視
- 監視間隔を30秒、1分、2分、5分、10分から選択
- オフラインから配信中へ変化したタイミングでWindows通知
- API接続に失敗した場合は監視を止めず、次の監視周期で再試行
- 自動監視の有効/無効、監視間隔、配信開始通知を設定画面から変更
- 旧バージョンの設定ファイルを読み込み、新しい監視設定には初期値を補完

## 参考アプリをもとにした今後の改善予定

- yt-dlp / FFmpegによる映像・音声録画
- 再接続、タイムアウト、保存容量監視
- ファイル名・フォルダー名テンプレート
- チャットのタイムスタンプ同期、エモート処理
- XML / SRT / ASS / JSON出力
- タスクトレイ常駐、起動時最小化、稼働ログ

## 注意点

- 自動監視はWindowsデスクトップ版のアプリを起動している間に動作します。
- Kick APIのClient IDとClient Secretを設定画面で登録してください。
- 監視対象が多い場合や監視間隔を短く設定した場合、APIへの問い合わせ回数が増えます。
- 配信開始通知は、監視中にオフラインから配信中への変化を検知したときに表示します。アプリ起動直後から既に配信中のチャンネルについては、初回確認では通知しません。
- 本リリースには映像・音声の実録画およびチャット取得機能はまだ含まれていません。
- チャット取得は、参考アプリ内で確認できた未公開Pusher/Web APIへの依存を避け、Kick公式API・公式イベントの要件に沿って後続実装します。
