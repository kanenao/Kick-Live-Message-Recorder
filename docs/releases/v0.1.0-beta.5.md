# Kick Recorder 0.1.0-beta.5 リリースノート

## 今回の変更

- Windowsアプリ上部メニューを日本語化
  - ファイル
  - 編集
  - 表示
  - ウィンドウ
  - ヘルプ
- テキスト入力欄・選択文字・リンクの右クリックメニューを日本語化
- Chromiumの標準UI言語を日本語に指定
- GitHubリポジトリ・不具合報告・バージョン情報へのメニュー項目を追加
- メニューから更新確認を実行できるように改善
- β版バージョンを 0.1.0-beta.5 に更新

## 継続して利用できる機能

- 登録チャンネルの保存・復元
- Kick公式APIによる配信状態の手動確認
- 30秒〜10分間隔の定期監視
- 配信開始時のWindows通知
- Kick API認証情報の暗号化保存
- GitHub Releasesからの自動更新

## 注意点

- β版0.1.0-beta.4以前から更新する場合、既存の自動更新機能を利用できます。ダウンロード完了後、アプリを再起動して更新してください。
- 映像・音声の実録画とチャットの実取得はまだ開発中です。
- Windows向けインストーラーはコード署名証明書なしで作成されています。
