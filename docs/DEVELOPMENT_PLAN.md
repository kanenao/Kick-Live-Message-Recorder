# 開発計画

## 確定仕様

- 対象：自分の配信と他の配信者の配信
- 録画操作：自動・手動の両方
- 保存対象：映像・音声・チャット

## 開発フェーズ

### Phase 1: UI・プロジェクト基盤
- [x] React + TypeScript + Vite の初期画面
- [x] チャンネルの追加・削除（画面内の一時状態）
- [x] 自動/手動モードの表示切り替え（画面内の一時状態）
- [x] GitHub Actions の型チェック・ビルド確認
- [ ] Electronデスクトップ化と永続保存

### Phase 2: 配信検知・録画
- [ ] Kick公式APIによる配信状態の確認
- [ ] 自動録画の開始・終了制御
- [ ] 手動録画の開始・停止
- [ ] FFmpeg等による映像・音声保存
- [ ] 異常終了・ネットワーク切断時の復旧

### Phase 3: チャット記録
- [ ] 利用可能な公式API/イベントの認証要件を検証
- [ ] メッセージ本文・投稿者・受信時刻の保存
- [ ] 録画タイムラインとの時刻同期
- [ ] CSV/JSONエクスポート
- [ ] 削除要求・保存期間の管理

### Phase 4: ライブラリ・配布
- [ ] 録画一覧・検索・再生
- [ ] 保存先・容量・自動削除設定
- [ ] Windowsインストーラー
- [ ] GitHub Releasesで配布

## 技術上の注意

Kickの配信状態取得、録画可能なストリームの取得、チャット取得は別々に検証します。公式APIで取得できないデータを取得できると見せかけたり、未公開の内部APIを安定機能として扱ったりしません。認証・権限・利用規約に適合する方法を優先し、取得できない場合は機能制限を明示します。
