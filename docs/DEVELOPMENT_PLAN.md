# 開発計画

## 確定仕様

- 対象：自分の配信と他の配信者の配信
- 録画操作：自動・手動の両方
- 保存対象：映像・音声・チャット
- 初期配布対象：Windows（β版）

## バージョン方針

- `0.1.0-beta.1`：Electron起動基盤、設定保存、Windowsビルドパイプライン
- `0.1.0-beta.2`：Kick公式APIの手動配信状態確認、Client Secret暗号化保存
- 次のβ更新：Kick接続・配信状態検知の最小実装
- 後続β更新：手動/自動録画、チャット保存、録画ライブラリ
- `0.1.0-beta.3`：日本語UI・バージョン表示・GitHub Releases自動アップデート
- `0.1.0-beta.4`：参考アプリをもとにした配信の自動監視・Windows通知
- `0.1.0-beta.5`：Windows標準メニュー・右クリックメニューの日本語化
- `0.1.0-beta.6`：yt-dlpによる手動録画・自動録画の初期実装
- `0.1.0-beta.7`：アプリ名をKick Live Message Recorderに統一
- `0.1.0-beta.8`：ASS字幕・外部コメントログを映像に合成してMP4を書き出す
- `0.1.0-beta.6`：yt-dlpによる手動録画・配信開始時の自動録画・録画停止・限定的な再接続
- 正式版：権限・規約・異常系の確認、安定性テストを終えてから

## 技術上の注意

Kickの配信状態取得、録画可能なストリームの取得、チャット取得は別々に検証します。公式APIで取得できないデータを取得できると見せかけたり、未公開の内部APIを安定機能として扱ったりしません。認証・権限・利用規約に適合する方法を優先し、取得できない場合は機能制限を明示します。
