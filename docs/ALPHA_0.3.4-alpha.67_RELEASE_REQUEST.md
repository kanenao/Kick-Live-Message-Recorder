# Kick Live Message Recorder 0.3.4-alpha.67 公開申請

ユーザー要望：動画・コメント保存ファイル名をKick配信者名・配信した日付・時刻へ変更。

新規LIVE／VOD動画とLIVE／VODコメント（JSONL／TXT／ASS）のファイル名を統一。
既存のファイルを勝手に削除・移動・リネームしない。
旧形式と新形式を録画ライブラリで読み取る。
α版の連番を継続してalpha.67とする。

公開条件：GitHub Actionsの型チェック・自動テスト・Windowsインストーラー生成・α/β/latestマニフェストの実ファイル名とSHA512整合性の検査がすべて成功した場合にのみ公開。
