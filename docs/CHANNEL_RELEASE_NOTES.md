# Kick Live Message Recorder 1.0.0 — 初回製品版

Kick配信の録画・コメント保存・コメント付き動画生成に特化したWindows x64向け製品版です。

- **搭載機能**：LIVE監視、LIVE録画・VOD録画、コメント自動取得・保存、JSONL/TXT/ASS、録画ライブラリ、動画サムネイル、ニコ生風コメント付き動画生成とプレビュー。
- **搭載しない機能**：配信AI新聞、Ollamaによる記事生成・自動記事処理。これらはβ版のみで開発を継続します。
- **製品版専用更新**：`latest.yml` を使用。β版へ自動更新・切り替えできません。更新は自動確認・ダウンロード後に利用者が明示的に適用します。
- **β版からの選択**：β版の「バージョン更新」画面から製品版の公式インストーラーを選べます。製品版アプリ内からβ版へ変更する操作は提供しません。
- **データ保護**：製品版とβ版は別のアプリIDと設定領域を持ち、既存の録画・コメント・記事ファイルは自動で削除しません。両版を同時に監視させると二重録画になるため、旧版の監視を停止してください。

## 検証と既知の制約

自動回帰テスト、TypeScript型チェック、Electronビルド、Windows x64インストーラー生成、配布ファイル名と更新マニフェストSHA512の整合性をCIで検査します。

**実際のKick LIVE録画・コメント取得の長時間実機テスト、Windowsユーザー環境でのインストール・更新テストは未完了です。** CI合格のみで不具合ゼロ・あらゆる配信環境での動作を保証しません。問題が起きた場合はGitHub Issuesに再現手順を報告してください。正式製品版も修正リリースを継続します。
