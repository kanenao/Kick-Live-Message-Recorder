# Kick Live Message Recorder 1.0.1 — β版から移行したユーザー向け改善

Windows x64製品版の修正リリースです。録画・コメント・ASS・コメント付き動画生成・録画ライブラリは従来どおりです。

- **β版への復帰**：同じWindowsユーザーで以前にインストール済みβ版を起動した利用履歴がある場合だけ、「バージョン更新」に「β版に戻る」を表示。
- **明示的な許可が必要**：「β版の取得を許可」を押した後に表示される確認ダイアログで許可するまで、β版インストーラーはダウンロードされません。
- **製品版のみのユーザー**：β版利用履歴がない場合は復帰操作を提供しません。
- **既存β版ユーザー**：最新版のβ版（0.9.0-beta.93以降）を一度起動すると利用履歴が登録されます。
- **更新チャンネル**：製品版は `latest.yml` のみで自動更新、β版への自動移行・自動取得なし。
- **記事機能**：製品版には配信AI新聞・Ollama記事生成を搭載しません。β版のみ。
- **データ保護**：製品版とβ版は別アプリのまま共存し、録画・コメント・記事ファイルを削除しません。

自動テストとWindowsビルドで検証しますが、実際の長時間Kick配信・ユーザーWindows環境の動作確認は継続中です。
