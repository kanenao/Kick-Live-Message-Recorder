# Kick Live Message Recorder — β版と製品版を分けて配布

- **β版**：配信AI新聞（映像・音声・コメントからの記事生成）を引き続き開発・改善します。録画・コメント・動画生成も含みます。
- **製品版**：配信記事機能は提供しません。録画、LIVE監視、コメント取得・保存、ASS、コメント付き動画、録画ライブラリを中心に提供します。
- **手動版選択**：β版の「バージョン更新」画面からのみβ版・製品版を選べます。製品版では版の変更ボタンとIPCを提供しません。
- **自動更新**：β版は `beta.yml`、製品版は `latest.yml` をそれぞれ利用し、互いに自動切替しません。
- **旧α版**：履歴として残します。旧版の自動更新が壊れている場合は、新しいβ版のインストーラーで手動移行してください。
- **データ保護**：β版と製品版の設定領域を分離します。既存の録画・コメント・記事ファイルは移動／削除しません。

製品版の正式な公開には、Windows実機で録画・コメント・インストール・自動更新の受け入れ確認が必要です。CIの型チェック・単体テスト・Windowsビルド成功だけで、長時間運用の無事故を保証しません。
