# Kick Live Message Recorder — β版と製品版を分けて配布

- **β版**：配信AI新聞（映像・音声・コメントからの記事生成）を引き続き開発・改善します。録画・コメント・動画生成も含みます。
- **バージョンの同期**：β版の基本番号を公開済み製品版1.0.1にそろえ、`1.0.1-beta.95` とします。以後β版の基本番号は製品版より下げず、開発規模でpatch/minor/majorを選び、beta.Nの連番は維持します。
- **製品版**：配信記事機能は提供しません。録画、LIVE監視、コメント取得・保存、ASS、コメント付き動画、録画ライブラリを中心に提供します。
- **版選択と復帰**：β版からβ版・製品版を選べます。製品版1.0.1以降は以前にβ版を起動したユーザーだけ復帰可能です。いずれも利用者が確認画面で許可するまで別版のダウンロードは開始しません。
- **自動更新**：β版は公開済みβ版の `beta.yml` を検証し、版の一致を確認してからβ版だけを自動取得します。製品版は `latest.yml` だけを使用し、互いに自動取得・自動切替しません。
- **旧α版**：履歴として残します。旧版の自動更新が壊れている場合は、新しいβ版のインストーラーで手動移行してください。
- **データ保護**：β版と製品版の設定領域を分離します。既存の録画・コメント・記事ファイルは移動／削除しません。

製品版1.0.1は公開済みですが、Windows実機で録画・コメント・インストール・自動更新の一連の受け入れ確認は継続中です。CIの型チェック・単体テスト・Windowsビルド成功だけで、長時間運用の無事故を保証しません。
