# Kick Live Message Recorder 1.4.5-beta.113 — β版

- KICKs・ギフトサブスク監視を最大5配信ずつの2接続へ分割。上位10配信の対象が入れ替わっても既存のグループを可能な限り維持し、片方の再購読で他方を切断しない。1回の更新で新規接続は1グループまで。
- コメント・ギフト取得の一時エラーで前回観測値を直ちに消さず、最終取得から最大30秒まで明示付きで表示。15秒超または取得失敗中は新しい順位変動・推移記録を行わず、30秒超は未取得扱い。別範囲の数値は流用しない。
- 最大50位、10秒更新、別メニューでの監視継続、閲覧位置復元、等倍プレビューを維持。実際のKickギフト受信・Windows実機表示は別途検証が必要。
