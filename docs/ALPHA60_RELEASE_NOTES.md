# Kick Live Message Recorder 0.2.5-alpha.60

**α版（開発・先行テスト向け）の初回公開です。** 旧β版 v0.1.0-beta.50 は公開履歴として残します。製品版ではありません。

## 主な改善点

- **録画ライブラリ**：配信者別の一覧を広く表示し、縦スクロールとレスポンシブ表示を改善。
- **配信AI新聞**：記事とともに16:9の放送画面を表示。LIVE・録画記事の代表フレームに対応。
- **AI記事管理**：過去データを含む記事削除処理と回帰テストを改善。
- **LIVE音声解析**：音声FFmpegの異常終了・長時間無進捗を監視し、段階的な再接続・復旧を強化。
- **コメント・録画**：録画ライブラリのコメント閲覧、コメント付き動画の時間同期を改善。

## 配布

Windows x64 インストーラーを配布します。インストール後の更新確認用 `latest.yml` および差分更新用 `.blockmap` も同梱します。

## 注意事項

α版は開発途中であり、不具合が残る可能性があります。重要な録画や設定はバックアップを保管してください。GitHub Actionsのテスト・Windowsビルドが成功していても、すべてのKick配信やWindows環境での実動作を保証するものではありません。
