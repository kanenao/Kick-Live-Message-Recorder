# Kick Live Message Recorder 0.3.0-alpha.63

Windows x64向け **開発中のα版（Pre-release）** です。これまでの `alpha.62` から連番で更新しています。安定版ではありません。

## 録画安定化（最優先）
- LIVE録画が途中で終了した場合、KickのLIVE状態を確認。配信継続中なら分割ファイルを残して自動再接続します。
- 登録チャンネルの24時間監視を改善。配信開始直後だけでなく配信中にも録画プロセスの有無を確認します。
- 3分間動画ファイルが増えない状態を検出した場合に復旧を試みます。停止要求が応答しない場合は段階的に処理を終了させます。
- 手動停止した同じ配信は、自動監視が勝手に録画再開しないよう保護します。
- ファイル保存の有無を確認し、動画未生成・途中停止・正常終了を区別します。

## 録画とコメントの管理
- 複数のKick過去番組URLをまとめて登録。最大3本を並行ダウンロードし、進捗・経過時間・個別停止に対応します。
- 録画ライブラリを配信セッション別に整理し、録画動画・コメントログ・AI記事を関連付けて表示します。
- 再接続時の分割ファイルは同じ配信の録画として扱い、保存済み動画の誤削除・誤関連付けを防ぐ確認を追加しました。

## 自動更新
- α版の更新チャンネル向け `alpha.yml` と、旧クライアント互換の `latest.yml` を配布します。
- インストーラーにはyt-dlp、FFmpeg、ffprobeを同梱します。

## 既知の注意点
- GitHub Actionsの型チェック・単体テスト・パッケージビルドと、実機での長時間録画の成功は別の検証です。配信内容やネットワーク環境によっては欠落する可能性があります。
- 接続が切れた期間の映像をさかのぼって復元する機能ではありません。再接続前後の映像が別ファイルになる場合があります。
- LIVEの日別コメントログは同日の別配信と混在する可能性があり、紐付けの正確性が不明な場合は区別して表示します。
- α版には不具合が残る可能性があります。大切な配信の保存には別手段も併用してください。
