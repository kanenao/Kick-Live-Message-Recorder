# Kick独自ランキング（β版向け）
参考：ちくわちゃん、ショボンKICKランキング、Kickアクティブランキング、配信者勢いランキング。独自UIと集計であり、外部ランキングサイトのデータをスクレイピングしない。
- 公式API /public/v2/livestreams のページ取得（最大20ページ、1ページ1000件）、日本語/全世界。取得範囲が不完全なら暫定と表示。
- 同接順、前回比増加順、名前・タイトル・カテゴリ検索。最大500件保持、200件表示。順位変動は取得範囲が完全な場合のみ。
- サムネイル、配信者アイコン、タイトル、カテゴリ、開始からの経過時間、同接、前回差。画像はHTTPSのKickドメインのみ許可。
- 60秒自動更新（ランキング画面を表示中）、15秒連続取得制限、429は共通の待機時間を尊重。
- 未登録配信者も通常LIVE録画開始/停止可能。登録リストや自動監視設定を変更しない。ランキング圏外の録画も停止可能。
- Kick API認証設定が必要。過去の順位履歴・チャット勢い・日次集計・追っかけ録画との統合は未実装。Windows実機でのAPI・録画試験が必要。

## ローカルランキング履歴
- 取得成功時、範囲別の上位100件を5分に1回保存。過去7日間を保持し、古い日付ファイルは次回保存時に削除。ランキング表示中のみ取得し、非表示中・停止中・オフラインの欠測を補完しない。
- 過去24時間・7日間の観測最高同接、最高順位、観測回数を表示。暫定取得の順位は最高順位に含めない。視聴者数推移は観測点のみ表示。
- 監視・録画登録ボタンは確認後、既存の自動録画対象リストに追加する。既存の監視・録画設定に従う。月間・チャット勢い・追っかけ録画連携は未実装。

## 常時収集と受信コメント勢い
- 初期OFF、明示ONでアプリ起動中に指定範囲を5分間隔で取得（トレイ動作中を含む）。設定はPCに保存。アプリ完全終了・PC停止中は収集不可。既存キャッシュ・API制限を共有する。処理中のOFFは次回取得を止めるが実行中のリクエストは完了する場合がある。
- 受信済みLIVEコメントの現在の分を含む直近5分枠の件数をメモリで集計。新規チャット接続や本文・投稿者の追加保存なし。コメントを受信していない配信者は未観測でありゼロと扱わない。全体のコメントランキングではない。再起動でリセット。
- 月間集計・追っかけ録画連携は未実装。
