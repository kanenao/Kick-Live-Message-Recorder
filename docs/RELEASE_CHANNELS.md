# Kick Live Message Recorder — β版と製品版の運用

2026年11月23日から開発中のα版をβ版へ移行し、製品版を別のラインとして準備します。

| 区分 | 開発ブランチ | 版数 | 記事機能 | 配布／自動更新 |
| --- | --- | --- | --- | --- |
| β版 | `beta` | `0.8.1-beta.88` から | あり：映像、音声、コメント、LIVE記事、Ollamaを強化 | GitHub Pre-release、`beta.yml` |
| 製品版 | `stable` | `1.0.0` から | **なし**：メニュー、記事関連IPC、バックグラウンド記事処理を無効化 | GitHub通常Release、`latest.yml` |
| 旧α版 | 各 `v*-alpha*` タグ | 最終公開 `0.8.1-alpha.87` | 過去版として保持 | 履歴を保持。新しいα版は発行しない |

## 版の手動選択

β版の「バージョン更新」画面だけに「β版を選択」「製品版を選択」を設けます。製品版には切り替え画面・IPCを搭載しません。β版を残しておけば、β版からいずれの公開済みインストーラーにもアクセスできます。製品版は正式Releaseがない間は選択不可です。インストーラーを手動実行し、各版は別アプリとして共存します。

## コア機能

両版ともLIVE監視、自動／手動録画、VOD録画、コメント自動取得、JSONL/TXT/ASS出力、録画ライブラリ、コメント付き動画生成、ニコ生風リアルタイムプレビューを提供します。

β版のみ配信AI新聞の映像・音声・コメント解析、ローカルOllama、記事生成と再解析を継続開発します。製品版で記事メニューが見える・記事生成が自動起動する・記事IPCが呼べる状態は不具合として扱います。

## 版数と公開

- β版：`X.Y.Z-beta.N`。開発連番は旧αの `alpha.87` の次を採用して `beta.88` とし、以後更新ごとに増やす。X.Y.Zは機能規模に応じて更新する。
- 製品版：`1.0.0` 以降は重大な既知不具合がない状態で公開。テストだけで「不具合ゼロ」とは断定しない。
- β版の自動更新は `beta.yml`、製品版の自動更新は `latest.yml`。β版から製品版、製品版からβ版へ自動的に乗り換えさせない。製品版のElectron `appId` とユーザーデータ領域はβ版と分離する。
- GitHub Actions `.github/workflows/channel-release.yml` は `beta`／`stable` への通常pushで品質とWindowsビルドを確認し、`release/vX.Y.Z-beta.N`／`release/vX.Y.Z` ブランチの正しいバージョンのpushだけを公開対象にする。
- 配布前にWindows EXE・ファイル名・SHA512・自動更新マニフェストを照合する。失敗時は公開しない。履歴のある旧αタグやReleaseは上書きしない。

## 製品版公開の受け入れ項目

- [ ] TypeScript型チェック・回帰テスト・本番ビルド成功
- [ ] Windows x64インストーラーを作成し新規インストール／起動を確認
- [ ] 配信検知、LIVE録画開始／停止、再接続、VOD録画を実配信環境で確認
- [ ] コメント受信／保存／再読み込み、ASS変換・コメント付き動画の同期と再生を確認
- [ ] 自動更新 `latest.yml` と旧版からの更新、β版が誤配信されないことを確認
- [ ] 設定・動画・チャットの保護、再インストール・保存先変更、長時間運用を確認
- [ ] 記事メニュー、記事関連IPC、自動記事処理が製品版にないことを確認
- [ ] 既知の重大な不具合・依存ソフトのライセンス・更新ノートを確認

この実機受け入れが済むまでは製品版 `1.0.0` は**準備中**です。CI成功だけで製品版を正式公開しません。

## データ移行

製品版とβ版は別の設定領域を持ちます。既存の録画、コメント、配信記事のファイルは変更・移動・削除しません。製品版からは記事の機能を利用できませんが、記事データを自動削除しません。旧α版クライアントで更新ができない場合は、新しいβ版のインストーラーで明示的に移行してください。データ移行や設定のコピーは慎重に検証してから行います。
